# RedBrief｜小红书内容速读助手

一个面向小红书秋招非技术岗作品集的轻量 MVP：将招聘信息、新闻或长笔记，整理为“三句话摘要 + 关键词 + 行动提醒”。

## 为什么做它

截图中的讨论包含两条路线：

1. 会议录音 → 语音转写 → 自动纪要；
2. 提取网页内容 → 大模型归纳总结。

第一条路线涉及录音权限、语音识别、隐私合规和会议软件适配，首版成本较高。RedBrief 选择第二条路线，先验证最核心的需求：**用户是否愿意用一个工具减少阅读和整理长内容的时间**。

## MVP 用户流程

`粘贴内容 → 点击归纳 → 查看摘要、关键词和行动信息 → 一键复制`

首版刻意不做登录、账号体系和复杂设置，让用户在十秒内看到价值。


## 如何运行

直接双击 `index.html`，无需安装依赖。也可以用 GitHub Pages 部署。

## 项目结构

```text
redbrief-xhs/
├── index.html   # 页面结构
├── style.css    # 视觉与响应式布局
├── app.js       # 本地摘要、关键词和提醒逻辑
└── README.md    # 项目说明与面试讲法
```

## 说明

当前版本使用本地规则生成演示结果，不上传内容，也不调用外部模型。正式版本可接入网页正文提取服务和大语言模型，提高摘要质量。
